# 灵眼的认知哲学：投影、寻路与自维持

## 从设计哲学到认知哲学

作者：guaidao2、coolmoon

《把渗透测试当作一场不完全信息博弈》回答的是“灵眼为什么这样设计”。这篇继续往前一步，问两个更底层的问题：

1. 一个只能通过有限观测接触目标的 agent，究竟能“知道”什么？
2. 在这种有限性下，它应该怎样选择下一步，才不算自欺？

这篇不是产品功能说明，也不声称解决了通用智能。它只是把灵眼背后的一组假设写清楚，让它们彼此不矛盾，并且能被实验推翻。文中会区分三个层次：本体论（世界是什么）、认识论（我们如何知道）、工程层（代码里怎么落）。混在一起谈，最容易产生看似深刻、其实不可检验的句子。

## 一、两个基底命题

### 命题 P1：物质与信息是同一事物的两种描述

不存在脱离物质的信息，也不存在不承载信息的物质。一个系统的状态总要通过某种物理载体与其他系统发生关联；观测不是“把信息从对象里取出来”，而是观测者的测量接口与对象状态之间的一次真实耦合。

因此，观测是**投影**：

> 对系统 S 和观测者 O，O 得到的不是 S 的完整状态，而是 P_O(S) —— 一个受 O 的测量基、分辨率和噪声限制的低维像。

这个“投影”不是幻象，也不是“世界只存在于观察中”。投影是真实的因果痕迹：对象确实影响了观测者。我们接触不到“物自体”，但接触得到物自体留下的可观测面。这两句话必须同时成立，否则就会滑向唯心论，或者滑向“观测即全部”的独断。

### 命题 P2：离散符号是多个预测系统之间的压缩协议

语言、数学、协议字段不是智能的必要条件，而是通信的效率工具。连续经验在单个系统内部可以保持连续；一旦要跨系统传递，就必须压缩成离散符号。符号是有损编码：它让两个系统能以较低成本对齐，但也会截断连续经验里的细节。

符号一旦产生，又会反过来改变认知：系统开始用符号的切分方式看世界，把连续感知压成离散类别。这是“私我”和“公我”分裂的工程版本——内部连续模型与外部符号身份不再完全一致。

### 推论：安全测试是一个不适定的反问题

如果观测是投影，那么“从观测反推目标隐藏结构”就是一个反问题。反问题通常不适定：多组隐藏状态可能产生同一组观测，噪声和对手的主动伪装还会让映射更不稳定。

所以灵眼不能把“一次观测”当成“系统真相”。它能做的是：记录投影的条件（信道、层、时间；执行环境写在证据正文或备注里，目前不是独立字段），保留多个候选解释，用新的投影去区分它们。这不是谨慎的姿态，而是认识论上的必要条件。

## 二、agent 是智能的载体，不是智能本身

日常语言里，“agent”和“智能”经常被混用。本文做一个区分：

- **agent**：有边界、能感知、能行动、有目标、在时间上持续存在的系统。
- **智能**：agent 在不确定环境中维持预测、行动和适应的能力（这是关系性定义，不是某个模型内部的固定属性）。

一个恒温器也是 agent：有感知、有目标、有行动，但智能很低。一个很强的模型如果没有持续目标、记忆和自我模型，可以表现出很高的任务能力（日常说“很聪明”），却未必构成我们定义的完整智能体。agent 提供主体性，智能提供适应性；两者叠在一起，才是我们平常说的“一个智能”。这里的“聪明”指任务能力，不等于本文定义的智能。

这个区分对灵眼很重要。灵眼的指挥官是一个 agent，但它不是一个“以自我保存为终极目标”的 agent。它的目标由使用者给定，它的边界由授权与范围给定，它的记忆是本次交战的信念图。灵眼不追求“让自己继续存在”，也不把资源扩张写进目标函数——那会把授权测试变成别的东西。

可以用一句更准确的话概括：

> 灵眼借用 agent 的主体性来组织行动，但不把“自维持”当作 agent 的目标；自维持只作为理解智能的分析视角。

## 三、寻路同构：物理路与成功路共享拓扑

“寻路”最早长在物理空间里：当前点、可走的边、代价、目标点。但“通往成功的路”也可以是同一套结构：

- 当前点 = 当前信念；
- 可走的边 = 可执行的实验或动作；
- 代价 = 时间、token、暴露面、风险；
- 目标点 = 目标状态（漏洞确认、覆盖完成、权限获得等）。

两者共享的是图拓扑，不共享语义。所谓“成功路也是路”，本质是：

> 在概念化的信念图上，做目标条件的路径搜索。

这不是把“成功”当成一个模糊词，而是把目标变成图上的终态，把边标成有前置条件、预期观测、代价和不确定性的转移。路径搜索算法不需要知道脚下是地板还是凭据；它只需要知道这条边能不能走、走过去预期看到什么、值不值得走。

这里有两个必须区分的图：

- **探索图**：记录“相信什么、还缺什么”，是信念结构与实验计划；
- **攻击路径**：候选或已验证的因果链，是交付物候选，不是探索本身。当前 schema 的默认状态是 `suspected`，记录时不强制要求证据或前置条件；把它升级为“已验证”需要额外的证据与判断。

两者可以互相引用，但不能混成一张图。把探索图当成攻击路径，会让“可能性”伪装成“已证实”；把攻击路径当成探索图，会让计划失去开放性。

### 概念层与关系同构

如果每条边都只能用具体资产、具体 payload 描述，那么跨目标迁移几乎不可能。更有用的抽象是**关系模板**：

> 前置条件 → 动作 → 预期观测 → 后置条件

例如“存在一个未鉴权的入口 → 发送一个探测 → 返回差异化响应 → 该入口可被未授权访问”。这个模板可以映射到不同资产、不同协议、不同 payload，而不绑定表面特征。

这也解释了一个常见的迁移失败：复用具体特征（某个 payload、某个版本号）往往不成立，复用关系结构（前置条件与观测的对应）才可能成立。概念层的价值不是给节点起漂亮名字，而是把关系从表面语义里剥离出来。

## 四、结构生长与修剪：容量不是无限调参

如果一个系统面对的环境复杂度超过其固定容量，它必须能改变结构（节点、连接、概念类型），而不只是调整参数。但“生长”不是越多越好：生长昂贵，修剪便宜；没有修剪的生长会把系统变成一堆低贡献连接。

一个有用的工程类比是蚁群：

- 信息素 = 成功路径的压缩记忆；
- 挥发 = 丢弃过时或低价值的路由权重；
- 随机选择 = 保持探索，避免锁死；
- 正反馈 = 强化有效边；
- 停滞检测 = 重置或提高探索。

把蚁群搬到灵眼，需要先分清两件事：

1. **可以挥发的是工作假设和路由权重**：某条路径最近没成功、某个概念长期没被用到，可以降权、归档、标记 stale；
2. **不能删除的是原始证据**：审计、报告、复现都依赖 evidence。老数据可以分层、压缩、冷存，但不能因为“暂时没用”就物理删除。

对抗环境里，很多“当时没用”的信息过两天可能变成关键线索。因此遗忘必须是可逆的衰减，不是不可逆的抹除。热层放当前信念，温层放历史假设，冷层放原始证据；越冷越便宜，但可回读。

结构生长的触发条件也应该克制：重复出现无法用现有概念解释的观测、现有边类型反复不够用、预测误差持续无法通过参数调整降低。没有这些信号，生长只是增加复杂度。

## 五、归纳、证伪与覆盖：没有绝对安全的系统

“过去太阳每天升起，所以明天也会升起”是归纳，不是证明。随机森林、大语言模型都是归纳器：它们能推演“通常如此”，但前提是世界足够平稳。安全场景偏偏有人会主动改变分布、制造例外。

所以认知分工要更准确：

- **溯因（abduction）**：面对观测，提出“哪一种解释最可能”的假设；归纳提供先验和规律，但不负责发明解释；
- **证伪**：设计能推翻假设的实验，寻找反例；
- **枚举**：一种覆盖策略，在有限预算内搜索假设空间，本身不是与归纳并列的认知模式。

它们不能互相替代。只靠归纳，会把“过去没打穿”当成“安全”；只靠证伪，会缺少方向；只靠枚举，会被组合爆炸拖死。溯因给出方向，归纳给出先验，证伪负责检验，枚举负责覆盖预算。

“世界上不存在绝对安全的系统”这个判断成立。但“一定是穷举和信息枚举不到位”这句话要小心：如果“枚举”被定义成包含一切因素，它就变成同义反复；如果只指输入枚举，那么设计缺陷、侧信道、供应链、人的因素又不在里面。更准确的说法是：

> 任何结论都只是在当前威胁模型、当前预算、当前观测能力下的“未发现”，不是“不存在”。

找到一个漏洞是存在性证明；没找到只是证伪失败。灵眼的覆盖率应该覆盖“资产 × 攻击类 × 前置条件 × 观测信道”的假设空间，而不是只数资产。报告必须区分：已测、有证据、未覆盖、未验证。不能把“没发现”写成“安全”。

大语言模型在这里的位置也要摆正：它擅长提出假设、生成候选、压缩经验，但它不是证明器。它可以帮你决定“先问什么”，不能替你决定“已经知道”。验证必须来自工具、观测和可复现证据。

## 六、因果闭环与因果一致性

一个自洽的时间闭环可以这样成立：后来的行动参与构成了先前的事件，先前的事件又导致后来的行动。它不是祖父悖论——祖父悖论要求改变已经发生的历史；闭环没有改变历史，只是让历史成为一个固定点。

这种结构在逻辑上可解，代价是解释学循环：闭环里的某些事件没有闭环外的“第一因”。这不是矛盾，但也没有独立起源。

灵眼不做时间旅行。下面是这套结构在灵眼里的**设计目标**，不是当前已全部实现的现状；当前只有复测独立记录与证据不可变，自动 stale 级联、环检测与反事实回放都还没有落地。

1. **引用完整性**（目标）：finding 依赖 evidence，evidence 依赖 intent/asset；删除或修改时级联标记 stale，不硬删历史。
2. **环检测**（目标）：攻击路径出现环时标成 assumption/loop anchor，要求额外证据，不静默当事实。
3. **反事实回放**（目标）：分支模拟不写主图；只有前置条件自洽的路径才允许提交。
4. **版本化信念图**（目标）：复测更新是追加版本，不覆盖旧结论；旧路径可追溯。当前复测有独立记录，但 finding 状态仍可能被后续操作改写，尚未做到完整追加版本。

一句话：把“时间旅行”换成“可追溯的因果账本 + 自洽性检查”。这是设计方向，不是已经闭合的实现。

## 七、可靠性、迁移与过程选择

一个 agent 不可能永远自己扫，也不可能永远问别人。它需要在“问”与“自己找”之间切换，而切换依据是对过程可靠性的在线估计。

灵眼可以从这里借三件事：

1. **多假设可靠性**：不要单点信任一个分数。一个探针连续失败，不代表这个信道永远无用；一个子 agent 一次出错，也不代表它整体不可信。保留“可能变好/可能变坏”的多个假设，环境恢复后不会永久锁死。
2. **保守迁移**：同构经验升可靠性，异构经验降可靠性，平局也降。新目标是否复用旧策略，要先验证“像不像”，而不是无脑迁移。
3. **关系模板优先**：复用“前置条件 → 动作 → 观测”的关系，不要复用具体 payload、版本号或资产表面特征。

多 agent 的编排由 DeepSeek Harness 提供，灵眼不重复造一套派发框架。灵眼最多在现有派发之上做一层可靠性评估：哪个子 agent、工具或信道更可信；这不等于给 agent 自主攻击权限。

## 八、工程映射与诚实边界

哲学要能落地，必须写清楚哪些已经实现、哪些只是方向。下面这张表是本文与代码的对应关系，状态按当前版本如实标注。

| 概念 | 灵眼里的落点 | 状态 |
|---|---|---|
| 观测是投影 | evidence 的 channel、layers、createdAt；fact 的 basis/confidence/provenance；执行环境写在正文/备注 | 部分实现（无显式隐藏变量字段） |
| 信念而非真相 | facts 作为信念更新算子；negative/assumed 保留 | 已实现 |
| 探索图与攻击路径分离 | graph/edges 与 attack_paths 独立 | 已实现（攻击路径写入见 0.1.4 修复） |
| 目标条件路径搜索 | 无路径搜索器；ly_next 只做依赖门控、优先级、运行状态和资产数的启发式前沿排序 | 未实现，方向 |
| 概念层/关系模板 | 无独立概念表 | 未实现，方向 |
| 结构生长/修剪 | 无运行时结构生长 | 未实现，方向 |
| 蚁群信息素/挥发 | 无边权重衰减 | 未实现，方向 |
| 因果一致性/版本化 | 复测独立记录；证据不可变；尚无自动 stale 级联、环检测、反事实回放 | 部分实现，方向 |
| 多假设可靠性 | 无叠加态估计 | 未实现，方向 |
| 溯因/证伪/覆盖 | 覆盖率按证据算；报告列信念缺口；排序尚未使用信息增益 | 部分实现，覆盖维度仍偏资产 |

这张表故意不好看。它防止文章把“想法”写成“已经完成”，也防止读者把灵眼当成一个已经闭合的系统。

## 九、可证伪的预测

如果这套哲学只是好听，它应该经不起实验。下面几条是可检验的，失败就应该如实记录：

1. 在相同预算下，按“能区分多少候选假设”选择探针，比只按覆盖率选择，重复探测率更低、有效发现更多。
2. 给边加信息素与挥发，在目标规则变化后，比静态排序更快恢复有效路径；但如果环境平稳，优势可能消失。
3. 复用关系模板的冷启动，比复用具体特征更好；零样本迁移不保证成立。
4. 删除一个证据后，依赖它的 finding/path 能被正确标记 stale，且不会误伤无关结论。
5. 多假设可靠性比单点可靠性更不容易被一次误导永久锁死，但可能更保守。

这些预测都允许失败。失败不是“哲学错了”，而是告诉我们这套建模的边界在哪里。

## 十、这套东西不保证什么

第一，它不保证找到所有漏洞。投影有损，枚举有预算，对手会主动制造噪声。

第二，它不保证“没有漏洞”。未发现不等于安全，报告必须保留这个区别。

第三，它不保证路径最优。ly_next 是启发式排序，不是求解器。

第四，它不保证跨目标迁移。关系同构需要验证，零样本迁移很可能失败。

第五，它不把 agent 的自我保存当作目标。授权、范围、证据、报告是不可变约束；探索只能在这些约束之内。

第六，它不把哲学当证明。本文给出的是假设、映射和可证伪预测，不是数学定理。

## 结语

灵眼的认知哲学可以压缩成四句话：

> 我们只能看到投影，不能看到系统本身。  
> agent 是智能的载体，不是智能的证明。  
> 寻路是在信念图上做目标条件搜索，不是在清单上打勾。  
> 没有绝对安全，只有当前观测与预算下的“未发现”。

把这四句话写进数据结构，比把它们写在文章里难得多。这篇文字只是把方向写清楚；剩下的，交给实验和 review。
